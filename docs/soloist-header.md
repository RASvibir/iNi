# Soloist Header — uXu + iNi logo

## Why the Code Embed did nothing to the header

**Code Embed** only fills a *page section* in the body.  
The top bar is the separate **Header** block. Change that with **Upload Logo**.

## What to do (2 minutes)

1. In Designer, click the purple **Header** box at the top  
2. Under **Logo**, click **Upload Logo**  
3. Upload this file from your Mac:

   `/Users/ras.ip/iNi/docs/soloist-header-logo.png`

4. Optional fallback text: **Settings → Company name** → `uXu`  
5. **Save Draft** → **Publish**  
6. Hard-refresh https://soloist.ai/uxu
