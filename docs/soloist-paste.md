# Soloist — Code Embed (iNi brand section)

Use Designer **Add section → Code Embed**. This is a quiet brand presence for
**iNi** — community doors, not a sales block.

## Steps

1. Open [soloist.ai/designer](https://soloist.ai/designer)
2. **Add section → Code Embed** (after *How to practice iNi*, before *Links*)
3. **Section Heading:** set to `iNi` or clear it if Designer allows  
   (the embed already shows the **iNi** wordmark — avoid “Code Embed” as the title)
4. Open [`soloist-code-embed.html`](./soloist-code-embed.html)
5. Copy from `<section` through `</section>` (include the `<style>` block)
6. Paste into the **Code** field
7. Choose a **light** color preset
8. **Save Draft** → Preview → **Publish**

## Tone

- Brand-forward: **iNi** is the hero signal in the section
- Not commercial: no “join / buy / verify / get started” pitch
- Doors only: I Pages · Forum · The stack · paper-trail repo

## Smoke check

1. Section reads as **iNi** first, then the three doors  
2. Links open I Pages, Discussions, and `#stack`  
3. No product-speak or membership CTA
