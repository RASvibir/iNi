# How to use this file

1. **Copy** this file to a new name that matches your slug  
   Example: `your-slug.md`
2. **Fill the top fields** (the block above this heading):
   - `name` — shown as **I am {name}**
   - `slug` — same as the filename (without `.md`)
   - `attested_at` — today’s date as `YYYY-MM-DD`
3. **Write your page** in the sections below — freeform, non-judged.
4. **Open a pull request** on the iNi repo.

Optional later:

- `tagline` — short line under your name
- `portrait` — `https://…` or `/i/avatars/your.jpg`
- `theme` — `ink` · `paper` · `terminal`
- `layout` — `free` · `compact` · `wide`
- Crown fields — only if you want the honor layer (`crown_status: active`, then `wear_crown: true` for the border)
