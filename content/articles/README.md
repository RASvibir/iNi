# Community articles

Practice notes, provenance write-ups, and authorizations live here as Markdown.

## Add an article

1. Copy `_TEMPLATE.md` to a new file: `YYYY-MM-DD-short-slug.md`
2. Fill the front matter honestly
3. Open a pull request

Articles are **self-attestation**. Merging means the community accepted the
note as documentation — not a legal certificate, not membership enrollment.

Console opt-in on **0?0** / archive `data.json` remains the primary protocol path.
